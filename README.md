# AVORA — Архітектурне бюро

Лендинг-портфоліо студії сучасної архітектури та дизайну інтер'єрів AVORA.

## Технології
- HTML5 (семантична верстка)
- Tailwind CSS та кастомні CSS-змінні
- JavaScript (інтерактивний калькулятор вартості та слайдер До/Після)

## Функціонал
- Портфоліо реалізованих об'єктів (Резиденція на схилі, Пентхаус, Бутик-готель)
- Інтерактивний розрахунок вартості проєктування за м²
- Вбудована карта, відеоогляд та форма зворотного зв'язкуgit ss
